📘 Aide - Maison X Réèle

1️⃣ Comment naviguer sur le site

Bienvenue sur Maison X Réèle ! Voici comment utiliser le site :

  • Utilisez le menu principal pour accéder aux différentes sections.
  • Cliquez sur les boutons colorés pour visiter les pages spécifiques.
  • Si un bouton ne fonctionne pas, vérifiez votre connexion internet.

2️⃣ Créer un compte

Pour profiter pleinement du site :

  • Cliquez sur le bouton Créer un compte.
  • Remplissez vos informations : prénom, email et mot de passe.
  • Validez pour accéder à votre compte personnel.

3️⃣ Accéder au Chat ou à l’aide

Vous pouvez obtenir de l’aide directement via notre chat intégré :

  • Cliquez sur le bouton bleu animé "Continuer".
  • Le chat vous guidera et répondra à vos questions.

4️⃣ Résolution des problèmes fréquents

  • Si vous oubliez votre mot de passe, utilisez le lien "Mot de passe oublié".
  • Pour tout bug, utilisez la page d’aide pour nous envoyer un message.
  • Assurez-vous que votre navigateur est à jour pour un fonctionnement optimal.
